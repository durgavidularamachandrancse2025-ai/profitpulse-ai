# ProfitPulse

## AI Profit Forensics & Decision Agent

ProfitPulse is an AI-powered Finance Controller that investigates
why merchant profitability changes, identifies evidence-backed root
causes, simulates financial decisions, and recommends corrective
actions with human approval.

## Razorpay AI Builder Internship 2026

**Track:** Track 4 — AI Finance Controller

## Core Workflow

Observe → Investigate → Explain → Simulate → Recommend → Verify

## Key Features

- Transaction-level profitability analysis
- AI-powered root-cause investigation
- Financial impact quantification
- Counterfactual "What-if?" simulations
- Evidence-backed recommendations
- Human approval workflow
- Financial audit trail

## Tech Stack

- Python
- FastAPI
- React
- PostgreSQL
- Pandas
- NumPy
- Scikit-learn
- LLM-based agent orchestration

## Vision

ProfitPulse helps merchants move from simply knowing what
happened to understanding why profitability changed and
what decision could improve it.
